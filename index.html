🚦 About Semaphore Tracker

💡 The Idea

Ever wondered if you could predict when a traffic light will turn green? This project was born from a simple daily frustration: hitting every red light on the way to work.

By tracking the timing patterns of traffic lights, we can predict their current state and even know when they'll change - helping you plan the fastest route!

💭 Concept & Vision

Rodrigo Lira
rodrigoclira.github.io

Rodrigo conceived the idea and guided the entire development process, defining features, user experience, and the vision of turning traffic light frustration into a predictive tool for optimal route planning.

"An idea that became true with agent AI"

🤖 Development

Claude Code by Anthropic

The entire application was developed by Claude Code, an AI-powered coding assistant. From database design to mobile-responsive UI, from prediction algorithms to PWA implementation - every line of code was written through AI collaboration based on Rodrigo's vision.

This project showcases the power of human creativity combined with AI capabilities, where clear vision meets autonomous development.

🛠️ Technical Stack

  • Frontend: Vanilla JavaScript, HTML5, CSS3
  • Database: Supabase (PostgreSQL)
  • Hosting: GitHub Pages
  • AI Assistant: Claude Code by Anthropic
  • Features: Geolocation API, Real-time predictions

🎯 How It Works

  1. Record when you see a traffic light change state (open/closed)
  2. The app calculates average timing patterns
  3. Predictions are made based on historical data
  4. View all your semaphores in dashboard mode for route planning
  5. Reset history when timing patterns change
